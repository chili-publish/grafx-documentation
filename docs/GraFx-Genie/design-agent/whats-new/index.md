# What's new in the Design Agent

The [Design Agent](/GraFx-Genie/design-agent/) is in [Beta](/release-notes/feature-maturity/#maturity-how-finished-it-is) and changes often, without a platform release note for every step. This page is the change log: one dated entry per change to what the agent can do, newest first. Scan down to the date of your last visit to see what is new since then. Platform-wide releases are still announced in the [release notes](/release-notes/).

## 2026-10-14

**Beta available for everyone.** The Design Agent moves from the Alpha workspace into the production GraFx Studio workspace, with a Beta label, in every environment unless switched off in [AI opt-out](/GraFx-Genie/design-agent/manage/#opt-out-per-environment).

- Chat in the template workspace, opened from the GraFx Genie icon; the conversation persists while the template is open.
- Stop button, one undo step per turn, arrow-key prompt history, conversation starters.
- The Brand Kit is the source of truth: colors, media, text styles and components, with [descriptions](/GraFx-Genie/design-agent/brand-kit-descriptions/), replace the Alpha's GraFx Genie settings. Components can be added to a Brand Kit.
- [Custom skills](/GraFx-Genie/design-agent/skills/) per environment, created with GraFx Genie or by hand, with import and export.
- Answers to how-to questions grounded in the GraFx documentation, with a link to the page.
- Variable descriptions, read and written by the agent.
- Template utilities: explain a template, inspect another template, copy variables, Actions, layouts and animations between templates.
- Layout settings including bleed; copy settings from another layout.
- Display names for layouts, variables and list items.
