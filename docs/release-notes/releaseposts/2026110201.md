# CHILI GraFx: AI opt-out for GraFx Labs and platform improvements

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

Admins can now switch GraFx Labs off per environment, and the subscription and environment overviews show more of the details you need for support and integrations.

## ✨ New & Improved

### AI opt-out for GraFx Labs

- **Switch GraFx Labs off for an environment** from the new **AI opt-out** section in Environment settings. When it is off, GraFx Labs and its experiments are hidden for every user in that environment — see [Turn GraFx Labs off for an environment](/CHILI-GraFx/concepts/grafx-labs/#turn-grafx-labs-off-for-an-environment).
- **Only Subscription Admins and Environment Admins** see and change the setting. It is on by default, so nothing changes until an admin switches it off.

### Subscriptions, environments and renders

- **Subscription ID on the subscription details**, ready to copy — see [Subscriptions](/CHILI-GraFx/concepts/subscriptions/).
- **ID and Region columns** in the My environments list — see [Environments](/CHILI-GraFx/concepts/environments/#environment-settings-access).
- **The rolling average matches your contract.** Subscriptions on a 3-month average now see the 3-month value and label instead of the 6-month one — see [Renders](/CHILI-GraFx/concepts/renders/#fair-use-policy).
- **Total renders per environment.** The renders graph now also shows the total when you filter on an environment, and for All environments.

### Working with lists and content

- **Refresh output tasks** with a new button next to the search and filters — see [Output Tasks](/GraFx-Studio/guides/output/tasks/#overview).
- **Duplicated templates keep their tags** — see [Manage & Use Tags](/GraFx-Studio/guides/use-tags/#assign-tags-to-a-template).
- **Consistent multi-select in grid view.** Selection resets on search, sort and when opening a collection, as it already did in list view.
- **Subject types fall back to Default.** In the media detail view, a subject type without its own Subject Area and POI now shows the Default values, the same as in GraFx Studio — see [Subject type](/GraFx-Media/guides/smart-crop-subject-area/#subject-type).
- **GraFx Publisher is hidden** in environments of subscriptions that don't include it.

## 🐛 What's Fixed

- Fixed names showing incorrectly: internal spaces are kept for collections, user interfaces, rich text rules, media breadcrumbs and Brand Kit colors and styles, and leading or trailing spaces are no longer accepted.
- Fixed Brand Kit spot colors ending up with a duplicate spot name when switching a color to spot.
- Fixed kerning being off for Brand Kit text styles, so they now render like local styles.
- Fixed fonts not being listed alphabetically after uploading several at once.
- Fixed text fields selecting everything on a double click or drag; you can now select a word or part of the text.
- Fixed browsing a long collection carousel at some screen resolutions and browser zoom levels.
- Fixed the rename dialog showing under the delete dialog on the Projects page.
