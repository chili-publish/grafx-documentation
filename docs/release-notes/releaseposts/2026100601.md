# GraFx Experience 1.22: project card carousel and multi-claim SSO mapping

![GraFx Experience icon](/assets/icon-GraFx-Experience.svg){.rn_icon}

GraFx Experience 1.22 makes projects easier to recognize at a glance, and gives admins more flexibility in how SSO users are assigned to user groups.

## ✨ New & Improved

### Project card carousel

Project cards now show a carousel with the template's main visual followed by a preview of each layout in the project, in both grid and list view. See [Project card previews](/GraFx-Experience/end-user/manage-projects/#project-card-previews).

### Map multiple SSO claims to user groups

Tenant admins can now map several SAML or OpenID Connect claims to user groups, each with its own value-to-group mapping. At login, users receive every matching group. Existing single-claim setups keep working without any changes. See [Single Sign-On](/GraFx-Experience/overview/roles-permissions/#single-sign-on-sso).

### Other improvements

- **Glossary navigation** — **View glossary** on a template now opens the GraFx glossary filtered to that template, and **Previous** takes you back to it. The GraFx glossary only appears in the side navigation when GraFx is installed.
- **Bulk downloads** appear as a single entry with the correct file count on the [Downloads](/GraFx-Experience/end-user/manage-projects/#downloads) tab, however many files they contain
- **Faster project lists** — the projects overview loads faster, especially for organizations with many projects
- **GraFx subscription sync** — GraFx Experience reads your CHILI GraFx subscription when you save the [GraFx authentication](/GraFx-Experience/guides/connect-to-chili-grafx/#step-2-enter-the-credentials-on-the-grafx-authentication-page) and keeps it in sync every hour. An invalid Environment ID is now rejected with a clear error message instead of being saved.
- **Public API reference** — endpoints are regrouped into logical sections prefixed "Experience - …". Endpoint paths are unchanged.
- **Select assets** in the Assets extension — clearer filter options, and the version options are now labelled **No version history** and **Include version history**
- **Grip webhook timestamp** — a new **Grip webhook processed at** project field records when GraFx Experience finished processing a Grip order webhook
- **Images from CHILI GraFx in the CMS (available on request)** — on new GraFx tenants, CMS editors can pick images from the environment's default media connector, or upload new images to GraFx Media, straight from the CMS image picker. Contact our Client Success team to enable it.

## 🐛 What's Fixed

- Fixed layout display names showing the internal layout name in languages without their own translation
- Fixed long error messages on failed previews being cut off; they now wrap inside the card
- **1.22.0.1** — Fixed the **Outputs** list in the extension admin console not loading for organizations with many outputs. It now loads reliably, one page at a time.
