# GraFx Experience 1.23: output settings for production, variable data output and branding without Assets

![GraFx Experience icon](/assets/icon-GraFx-Experience.svg){.rn_icon}

GraFx Experience 1.23 gives admins control over how production PDFs are generated, brings variable data output to the portal, and lets new tenants brand their portal with images from GraFx Media.

## ✨ New & Improved

### Output settings for production outputs

Production outputs now use a PDF [output setting](/GraFx-Studio/concepts/output-settings/) from your CHILI GraFx environment, so options such as outlined text or crop marks are applied to the files your print partner receives.

- **Default PDF output setting** — pick which PDF output setting production outputs use, in the extension's Production output settings
- **Default PDF VDP output setting** — a separate default for projects whose template has an output data source

See [Set up a production channel](/GraFx-Experience/guides/set-up-production-channel/#step-3-configure-output-settings-optional).

### Variable data output

Projects built on a template with an [output data source](/GraFx-Studio/concepts/connectors-data/#two-ways-to-use-a-data-connector) now generate a batch — one file per record — delivered as a single ZIP file, for both downloads and production outputs. See [Projects with a data source](/GraFx-Experience/concepts/production-channels/#projects-with-a-data-source).

### Branding without the Assets extension

New GraFx tenants no longer need the Assets extension to brand their portal. Tenant and space logos, favicons, login page images and page images are uploaded straight to GraFx Media, and GraFx Experience keeps a copy for display. Existing tenants keep their current setup. See [Branding & login](/GraFx-Experience/admin/branding/).

- **Faster pages** — raster images from CHILI GraFx on CMS pages are resized for their container and delivered as WebP; SVG and GIF files are served as-is
- **Favicon validation** — favicons uploaded to GraFx Media must be PNG and 250 KB or less; invalid files are rejected before upload

### Other improvements

- **Version information in the user menu** — every user can see the deployed frontend and backend version and copy it for a support request. See [Login & access](/GraFx-Experience/getting-started/login-access/#checking-which-version-you-are-on).
