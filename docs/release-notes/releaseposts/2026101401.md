# GraFx Genie: Design Agent (Beta)

![GraFx Genie icon](/assets/icon-Grafx-Genie.svg){.rn_icon}

The GraFx Genie Design Agent is now available in [Beta](/release-notes/feature-maturity/#maturity-how-finished-it-is) for every environment, inside the GraFx Studio workspace. Describe what you want to create or change, and the agent operates GraFx Studio for you, working from your Brand Kit and following your organisation's own skills.

## ✨ New & Improved

### Design Agent in the GraFx Studio workspace

- **Chat with your Design System** — open the GraFx Genie chat from the workspace sidebar, describe a change, and watch it land on the canvas — see [Design Agent](/GraFx-Genie/design-agent/)
- **Explain and troubleshoot** — ask what a template does, why a frame is hidden, or how a Studio feature works; how-to answers are grounded in the GraFx documentation and link to the page used
- **Turn a design into a template** — make frames editable as variables, lock what must not change, add toggles through Actions, link images to GraFx Media or a connected DAM, set up a data source for batch output
- **Adapt a design to other formats** — add layouts by preset or custom size, rework the arrangement for a different proportion, make layouts responsive, animate animated layouts
- **Generate a design from a Brand Kit** — describe a page and the agent composes it from the kit's colors, text styles, media and components
- **Stay in control** — the agent asks before guessing, only does what you ask, and every turn is a single undo step; a Stop button ends a running turn — see [What you can ask](/GraFx-Genie/design-agent/commands/)

### Brand Kit as the source of truth

- Colors, media, text styles and components come from the Brand Kit attached to the template, guided by each element's **description** — see [Brand Kit descriptions](/GraFx-Genie/design-agent/brand-kit-descriptions/)
- Descriptions are edited on the Brand Kit detail page in GraFx Brand Kits, on the default theme — see [Update a Brand Kit](/GraFx-Brand-Kits/guides/edit/#describe-an-element)
- Components can be added to a Brand Kit, with a description that tells the agent when and how to use them

### Custom skills

- **Skills** are per-environment instructions that tell GraFx Genie how your organisation works: campaign layout sets, image sources, naming conventions, hard rules — see [Skills](/CHILI-GraFx/concepts/skills/)
- Create them by hand or let GraFx Genie generate them from a brief, in **Environment settings › Skills**; export and import as JSON to move them between environments — see [Manage skills](/CHILI-GraFx/guides/manage-skills/)

### AI opt-out

- Organisations can switch the Design Agent off per environment with the new **Design agent** toggle on the **AI opt-out** settings page; it is on by default — see [Enable, disable and data](/GraFx-Genie/design-agent/manage/)

!!! note "Known limitation"
    Results can differ between runs of the same prompt. Everything the agent produces is a regular, editable template, so check the canvas and adjust by hand or by asking again.
