# GraFx Experience 1.24: redesigned template page and live settings from CHILI GraFx

![GraFx Experience icon](/assets/icon-GraFx-Experience.svg){.rn_icon}

GraFx Experience 1.24 brings the whole template setup onto one page, and always uses the current GraFx Studio version and output settings from your CHILI GraFx environment.

## ✨ New & Improved

### One page to add and edit a template

Admins now configure a template on a single page, with **General**, **Versions** and **Translations** tabs and one save for all changes. See [Configure a Design System](/GraFx-Experience/guides/configure-design-system/).

- **Add template** opens a picker of the templates in your CHILI GraFx environment — no more copying template IDs
- **Main visual** — set it while adding the template
- **Field values** shows every field used on templates, ready to set or clear in one click
- **Workflow settings** is an ordered table that shows the output options of each user interface, and explains which row decides the editor UI — see [Configure workflow settings](/GraFx-Experience/guides/configure-design-system/#step-4-configure-workflow-settings)
- **Layout selection mode** explains what Multiple, Single and None mean for users
- **Versions tab** says which published version new projects use, and why **Publish** is disabled while previews are prepared; **Create version** is a single click — see [Template versioning](/GraFx-Experience/concepts/template-versioning/)
- **Template list** shows one line per template, with status, version and last update

### Studio version and output settings read live

GraFx Experience reads the GraFx Studio version, user interfaces and output settings from your CHILI GraFx environment when they are used. After a change in CHILI GraFx, the next editing session, preview or output picks it up; the **Refresh** and **Clear cache** buttons are gone. See [Settings are read live from CHILI GraFx](/GraFx-Experience/guides/connect-to-chili-grafx/#settings-are-read-live-from-chili-grafx).

### Other improvements

- **Sharper layout previews** — the **All layouts** view shows high-resolution previews that fill the card from the start. Templates published earlier get them with their next version.

## 🐛 What's Fixed

- Fixed publishing a template whose Design System has only one layout
- Fixed **All layouts** previews not updating when another data source row is selected
- Improved variable updates: they are faster, dropdowns no longer close unexpectedly, and temporary "connector not ready" errors no longer appear
- Fixed navigation dropdowns and submenus that were taller than the screen; they now scroll
- **1.24.1** — Fixed some layout previews being stored at thumbnail size, which made them look blurry
