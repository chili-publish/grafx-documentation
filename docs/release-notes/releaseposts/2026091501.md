# CHILI GraFx Environment API: Descriptions for Brand Kit text styles

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

Brand Kit media and colors already carry an optional description — a short explanation of what the element is for. Paragraph styles and character styles now carry one too.

## ✨ New & Improved

- Paragraph styles and character styles take an optional `description`, such as "body copy, for long-form text"
- A description belongs to the element, not the theme: you set it on the default theme, and every theme of the Brand Kit shares it
- It is returned in the resolved theme, so everything reading the Brand Kit sees the same guidance
- It is optional — existing Brand Kits keep working unchanged, and styles without a description return none

!!! info "What's next"
    Descriptions give AI-driven features the context that a name alone does not carry, so that [GraFx Genie](/GraFx-Genie/) can pick the right style for a given design. That is not available yet.

## 🐛 What's Fixed

- Fixed output generation failing on assets whose preview was reported as ready but never actually created. A preview that returns no result now counts as a failure instead of a success, so the problem surfaces straight away rather than breaking the output job later on.
