# CHILI GraFx Platform Update

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

## ✨ New & Improved

- **Act on an item without waiting for its preview.** The three-dot menu on an item is now available straight away, even while its preview is still loading — so you can rename, delete, or otherwise work with it without waiting ten seconds or more for the thumbnail.

## 🐛 What's Fixed

- **Fixed setting GraFx Media back as the default media connector.** Once another media connector was the default, GraFx Media could not be made the default again. It now can, at any time, and nothing changes in how you [set a default](/GraFx-Studio/guides/connector-hub/#set-a-default-connector).
