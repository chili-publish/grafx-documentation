# GraFx Experience 1.25: download from the editor, required fields and templates ready to configure

![GraFx Experience icon](/assets/icon-GraFx-Experience.svg){.rn_icon}

GraFx Experience 1.25 lets users download their work without leaving the editor, gives admins required fields on templates, and lists every template of your CHILI GraFx environment as soon as the extension is connected.

## ✨ New & Improved

### For users

- **Download from the editor** — download the whole project from the title bar, or a single layout from its tab menu. Unsaved changes are saved first, and you can keep editing while the file is generated. See [Download from the editor](/GraFx-Experience/end-user/edit-project/#download-from-the-editor).
- **One file stays one file** — a download with a single file arrives as that file, not as a ZIP, also from the **Downloads** tab
- **Grid or list view is remembered** on **My projects**, **All projects** and **Downloads**, and admins can set the default view. See [Grid or list view](/GraFx-Experience/end-user/manage-projects/#grid-or-list-view).

### For admins

- **Templates ready to configure** — when the extension is connected, every template of the CHILI GraFx environment is added with the new status **Needs configuration**, hidden from users until you activate it. See [Configure a Design System](/GraFx-Experience/guides/configure-design-system/#step-1-open-the-template).
- **Required fields on templates** — a template can't be activated until every required field has a value. Templates that are already active stay active. See [Make a field required on templates](/GraFx-Experience/guides/manage-fields/#make-a-field-required-on-templates).
- **Warning before changing the environment** — changing the CHILI GraFx environment now asks for confirmation, and templates that are not on the new environment become Inactive. See [Changing the environment](/GraFx-Experience/guides/connect-to-chili-grafx/#changing-the-environment).
- **Clearer progress on new versions** — the **Versions** tab shows that layouts and previews are being prepared, and a failed preview can be relaunched per layout. See [Publishing](/GraFx-Experience/concepts/template-versioning/#publishing).
- **CHILI GraFx look by default** — new tenants start with the colors, font and corner rounding of CHILI GraFx, and GraFx components on light-theme portals use white panels so they stay readable on any background. See [Default look](/GraFx-Experience/admin/branding/#default-look).

### For developers

- **`roles` in the page token** — the Extension SDK token of Experience and Admin Console pages includes the signed-in user's roles. See [Extension SDK JWT claims](/GraFx-Developers/grafx-experience/authentication/#extension-sdk-jwt-claims).
- **`getApiUrl()` returns the real API base URL** of the installation, the same one `apiCall()` uses. See [Call the platform API](/GraFx-Developers/grafx-experience/extension-sdk/#step-3-call-the-platform-api).

## 🐛 What's Fixed

- Improved reliability of large batches of previews and outputs: requests are spread out, so fewer outputs get stuck in **Queued**
- Fixed the template page showing at most 100 fields
