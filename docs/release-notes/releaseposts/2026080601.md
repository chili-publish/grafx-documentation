# CHILI GraFx Environment API: Descriptions for Brand Kit media and colors

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

## ✨ New & Improved

### Describe what each logo and color is for

A Brand Kit tells you *what* your brand elements are, but not *when* to use them. A name like "Logo alt" or "Accent 2" carries meaning for the person who created it and very little for anyone reading the Brand Kit afterwards — least of all for automation. [GraFx Genie](/GraFx-Genie/) can only pick the right logo for a dark background, or the right color for a call to action, if it knows what each element is meant for.

Media and color elements in a Brand Kit now carry an optional `description`: a free-text string explaining the purpose of that element.

```json
{
  "media": [
    {
      "name": "Logo",
      "mediaId": "df9c3576-f9ee-4c0e-bfdd-37e2f69da230",
      "description": "Primary logo, for light backgrounds"
    }
  ],
  "colors": [
    {
      "name": "Accent",
      "type": "cmyk",
      "description": "Accent color, reserved for calls to action"
    }
  ]
}
```

Two things to know:

- **A description belongs to the element, not to the theme.** It is set on the default theme and shared by every [theme](/GraFx-Brand-Kits/concepts/themes/) of the Brand Kit, so what "Primary logo" means stays the same on the master brand and on every sub-brand. Editing a description through a non-default theme returns `400 Bad Request`.
- **It is optional.** Existing Brand Kits keep working unchanged, and elements without a description simply return none.

Descriptions are accepted and returned by the Brand Kit endpoints of the Environment API. See [Elements](/GraFx-Brand-Kits/concepts/elements/#descriptions) for how they fit into a Brand Kit.
