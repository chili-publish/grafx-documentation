# CHILI GraFx Environment API: Unpublished changes, font lookups, and connectors

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

Components now tell you whether they have unpublished changes, reading font families is lighter on the server, and connector changes are saved more safely.

## ✨ New & Improved

### Unpublished changes indicator for components

- **Know when a component has changes that are not yet published.** Retrieving a single component now returns `hasUnpublishedChanges`, so you no longer need to compare timestamps yourself.
- **`true`** when the component has never been published, or has changed since its latest published version. **`false`** right after publishing.
- **Additive only.** Existing integrations are not affected.

```json
"hasUnpublishedChanges": true
```

!!! note "Known limitation"
    Until existing components are migrated to the new versioning, they all return `true`. The field is not yet returned when listing components.

### Lighter font family lookups

- **Font family lists scale with the page, not the environment.** Listing font families — including when sorted by file type — now reads only what the requested page needs, so responses stay fast as your font library grows.
- **Lighter font family details.** Retrieving a single font family, its styles, or its preview now loads only the data that request needs.
- **Same requests, same responses.** Existing integrations keep working as before.

The improvements apply to these endpoints:

```
GET /api/v1/environment/{environment}/font-families
```

```
GET /api/v1/environment/{environment}/font-families/{fontFamilyId}
```

```
GET /api/v1/environment/{environment}/font-families/{fontFamilyId}/styles
```

```
GET /api/v1/environment/{environment}/font-families/{fontFamilyId}/preview
```

## 🐛 What's Fixed

- **Fixed connectors disappearing after an interrupted save.** In rare cases, a connector update that failed halfway left the connector incomplete. From then on, the environment showed no connectors at all — not even GraFx Media — and connector requests failed. A connector update now either completes in full or keeps the previous version, and one connector that cannot be read no longer hides the others.
