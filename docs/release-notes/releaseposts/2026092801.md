# GraFx Studio: InDesign® and Photoshop® plugins 1.5.0

![GraFx Studio icon](/assets/icon-GraFx-Studio.svg){.rn_icon} <span class="version-label">v1.5.0</span>

Version 1.5.0 of the GraFx Studio Exporters for Adobe® InDesign® and Adobe® Photoshop® is available from the [plugin downloads](/GraFx-Studio/convert/downloads/) page.

## ✨ New & Improved

### Adobe® InDesign® plugin

- **Text backgrounds** — underlines with a negative offset, the common InDesign® workaround for highlighted text, are now exported as a GraFx Studio [text background](/GraFx-Studio/convert/Adobe-InDesign/#text-background-support)
- **Overprint** — Overprint Fill and Overprint Stroke on text and shape frames are now [carried over](/GraFx-Studio/convert/Adobe-InDesign/#overprint-support) to GraFx Studio
- Fixed an issue where documents with deeply nested frames did not convert correctly

### Adobe® Photoshop® plugin

- **Document resolution** — preflight now warns when a document is not 72 PPI, the fixed resolution of GraFx Studio, and lets you choose whether to preserve its [dimensions in pixels or millimeters](/GraFx-Studio/convert/Adobe-Photoshop/#document-resolution)
