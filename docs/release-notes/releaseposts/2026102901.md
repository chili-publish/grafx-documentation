# GraFx Genie: Design Agent in the component workspace

![GraFx Genie icon](/assets/icon-Grafx-Genie.svg){.rn_icon}

## ✨ New & Improved

### Design Agent in the component workspace

The [Design Agent](/GraFx-Genie/design-agent/) (Beta) now knows when you are building a [component](/GraFx-Studio/concepts/components/) instead of a template, and works within what a component can do.

- **Respects a component's limits** — it does not add extra pages, bleed, data sources, list variables, animation or nested components; it explains why and suggests an alternative where there is one
- **Protects the variable contract** — it lists the variables templates can map, and asks before a change that can break those templates, such as removing a variable or making it required
- **Sets up layout switching** — when a component has several layouts, it offers to add the Action that selects the right one by aspect ratio, by a variable, or both
