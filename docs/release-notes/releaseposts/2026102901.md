# GraFx Genie: Design Agent in the component workspace

![GraFx Genie icon](/assets/icon-Grafx-Genie.svg){.rn_icon}

The GraFx Genie [Design Agent](/GraFx-Genie/design-agent/) (Beta) is now fully supported in the component workspace. The agent knows when the open document is a [component](/GraFx-Studio/concepts/components/) instead of a template: it understands what a component can and cannot hold, how templates use it, and how to set it up so it works well once placed.

## ✨ New & Improved

### Design Agent in the component workspace

- **Build components by chat** — frames, layouts, responsive anchoring, variables and Actions work as they do in a template — see [Build a component](/GraFx-Studio/guides/build-component/)
- **Knows a component's limits** — ask for something a component cannot hold, such as an extra page, bleed, a data source, animation or a nested component, and the agent explains why and suggests what to do instead
- **Protects the variable contract** — the variables of a component are what templates map onto; before a change that can break those templates, such as removing a variable or making it required, the agent asks first
- **Internal variables stay internal** — a variable that an Action writes is kept out of the mapping list
- **Layout switching** — a template only fits a component into its frame and never switches its layout; when a component has several layouts, the agent offers to add the Action that picks the right one for the frame's aspect ratio
- **Frames past the canvas edge** — the agent points out frames that extend beyond the component's canvas, because that part shows in the template around the component frame
