# GraFx Studio: Pen tool and components in the Brand Kit

![GraFx Studio icon](/assets/icon-GraFx-Studio.svg){.rn_icon}

Available from GraFx Studio **1.49**.

## ✨ New & Improved

### Pen tool and custom clipping paths

Draw your own shapes on the canvas. The new Pen tool builds paths from anchor points and Bézier handles, for shape frames and for the clipping mask of image frames.

- **Custom shapes** — draw a path from scratch, or turn a rectangle, ellipse or polygon into an editable path — see [Draw a custom shape with the Pen tool](/GraFx-Studio/guides/shape-frame/#draw-a-custom-shape-with-the-pen-tool)
- **Custom clipping paths** — draw or edit the outline an image is clipped to — see [Draw or edit a custom clipping path](/GraFx-Studio/guides/image-frame/#draw-or-edit-a-custom-clipping-path)
- **Undo and redo** step through individual point edits while you edit a path; the finished edit is one step in the template's undo history

!!! note "Known limitation"
    Shapes and clipping masks made of several separate sub-paths can't be edited with the Pen tool.

### Components in the Brand Kit

A new **Components** tab in the Brand Kit panel places the components of the template's Brand Kit, next to its colors, styles and media. Components sync with the Brand Kit like its other elements. See [Place a component from the Brand Kit](/GraFx-Studio/guides/use-components/#place-a-component-from-the-brand-kit).

### Other improvements

- **Soft return** — press **Shift + Enter** for a line break inside the same paragraph — see [Text frame](/GraFx-Studio/guides/text-frame/#add-text-to-a-text-frame)
- **Subject Position** can extend beyond the frame edges — see [Define Subject Position](/GraFx-Studio/guides/smart-crop/#define-subject-position)
- **Visibility conditions** list layouts in layout tree order, with sub-layouts indented under their parent
- **Image picker** breadcrumbs start from the folder set on the image variable
- **SDK**: reorder layouts under the same parent, and follow Brand Kit theme switches with the new `brandKitThemeChanged` event

## 🐛 What's Fixed

- Fixed the theme selector not updating when the Brand Kit theme was switched by the SDK or GraFx Genie
- Fixed invalid Brand Kit colors, imported through set or sync, making a template fail to load — they are now rejected
- Fixed PDF output not matching edit mode for anchored frames
- Fixed video output of a static layout failing hard instead of reporting a clear error
- Fixed the color picker closing when changing a Stroke or Drop Shadow color after a component frame was added
- Fixed reloading a document not resetting mapped component variables
- Fixed incorrect rendering of consecutive duplicate letters in Arabic text
