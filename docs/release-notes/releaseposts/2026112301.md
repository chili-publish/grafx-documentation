# GraFx Studio: Pen tool and custom clipping paths

![GraFx Studio icon](/assets/icon-GraFx-Studio.svg){.rn_icon}

Available from GraFx Studio **1.49**.

## ✨ New & Improved

### Pen tool and custom clipping paths

Draw your own shapes directly on the canvas. The new pen tool lets you create and edit paths with anchor points and Bézier handles, and use them as custom clipping shapes on image frames.

- **Pen tool**: create and edit custom shapes by drawing paths on the canvas
- **Custom clipping paths for image frames**: draw and edit your own clipping shapes on image frames
- **Smarter undo/redo while editing paths**: undo and redo step through individual point edits. Once you apply the path, the whole change counts as a single undo step

!!! note
    Path editing isn't available for frames that contain multiple shapes.

See [Shape frame](/GraFx-Studio/guides/shape-frame/) and [Image frame](/GraFx-Studio/guides/image-frame/).

### Other improvements

- **Components in the Brand Kit panel**: a new **Components** tab lets you place components from your assigned Brand Kit — see [Use components](/GraFx-Studio/guides/use-components/)
- **Visibility conditions**: layouts now appear in layout tree order, with sub-layouts indented under their parent
- **Image picker**: breadcrumbs now start from the variable's defined folder instead of showing the full path
- **Subject position**: the subject area can now be moved and resized beyond the frame edges — see [Smart crop](/GraFx-Studio/guides/smart-crop/)
- **Soft return**: press **Shift+Enter** to insert a line break without starting a new paragraph

## 🐛 What's Fixed

- Fixed the color picker closing when changing a Stroke or Drop Shadow color after a component frame was added
- Fixed the theme dropdown not updating when the Brand Kit theme was changed outside the UI, such as through the SDK or GraFx Genie
- Fixed PDF output not matching edit mode for anchored frames
- Fixed reloading a document not resetting mapped component variables
- Fixed incorrect rendering of consecutive duplicate letters in Arabic text
