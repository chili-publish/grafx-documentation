# Environment API: Modify projects without opening the editor

![CHILI GraFx icon](/assets/icon-CHILI-GraFx.svg){.rn_icon}

The project modification endpoints are now part of the public Environment API. Your integration can update a project document on the server — fill its variables, change its layout or page size — without loading it in an editor.

## ✨ New & Improved

- **Set variable values, the selected layout and the page size** of a project in one request
- **Run the document's Actions** as part of the change, or apply only the values you send
- **Modify a stored project**, and the result is saved on the project
- **Modify a document you supply**, and get the result back without storing anything in the environment
- **Find the variable names and layout IDs to send** with the [Template Information Service](/GraFx-Developers/grafx-studio/template-information-service/)
- Works with documents from GraFx Studio **1.49** and later

```
POST /api/v1/environment/{environment}/projects/{projectId}/modifications
```

```
POST /api/v1/environment/{environment}/projects/modifications
```

```
GET /api/v1/environment/{environment}/projects/modifications/tasks/{taskId}
```
