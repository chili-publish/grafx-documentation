# Brand Kit  

A container of [brand elements](/GraFx-Brand-Kits/concepts/elements/) and assets (colors, fonts, media, paragraph - & character styles, components) that define a visual identity.  

- Defined at the **environment** level

A Brand Kit can carry variations of its visual identity through [themes](/GraFx-Brand-Kits/concepts/themes/): the default theme defines the full brand, and additional themes override only what differs.

A Brand Kit is also the source of truth for the [GraFx Genie Design Agent](/GraFx-Genie/design-agent/): when the agent designs or adapts a template, it takes colors, media, text styles and components from the Brand Kit attached to the template, guided by each element's [description](/GraFx-Brand-Kits/concepts/elements/#descriptions).
