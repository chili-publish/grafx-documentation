# Manage Folders in GraFx Media

## Introduction

GraFx Media is used to store your assets you will use in [GraFx Studio](/GraFx-Studio/) and [GraFx Publisher](/GraFx-Publisher/).

Assets are arranged in folders and subfolders.

Assets can be uploaded in a folder, not on the root level of GraFx Media.

![The Upload button greyed out at root level, with the tooltip "Uploads are only allowed inside folders."](rootlevel.png){.screenshot-full}

## Add a folder

Click the "Create folder" button, and enter a folder name.

![The Create folder dialog with an empty "Folder name (required)" field](newfolder.png){.screenshot}

## Rename a folder

Hover the mouse over a folder, and click on the "..." menu.

Choose the "Rename" option.

![A folder tile with its "..." menu open, offering Rename above a red Delete](rename.png){.screenshot}

Confirm in the dialog box.

![The Rename dialog, its folder name field pre-filled with the folder's current name](rename2.png){.screenshot-full}

## Delete a folder

Hover the mouse over a folder, and click on the "..." menu.

Choose the (red) "Delete" option.

![The same folder "..." menu, this time with the red Delete entry as the target](rename.png){.screenshot}

Confirm your delete action, by clicking the "Yes, delete" button.

All contents of the folder will be deleted.

![The Delete folder confirmation asking whether to delete the folder and its assets, with a red "Yes, delete"](delete2.png){.screenshot}
