# Output to MP4

## Select the right Layout

In the tree of layouts, select the one you wish to output.

![Layouts panel with the Leaderboard layout selected for MP4 output](output-1.png){.screenshot}

![The Leaderboard layout on canvas — the Chill Water banner that will become the MP4](output-2.png){.screenshot-full}

## Check the timeline

Have a quick glance at your timeline. Take the Scrubber, and run through the timeline. This will reassure you, this is the animation you will output.

![The scrubber dragged along the timeline, playing back the banner animation before MP4 output](output-3.gif){.screenshot-full}

## Output (to MP4)

Click "Export as" and choose MP4 in the dropdown.

![The export menu, with Export as MP4 listed above the GIF, PNG and JPG options](export.png){.screenshotsmall}

When the export is ready, your browser will download the file into your downloads folder.
