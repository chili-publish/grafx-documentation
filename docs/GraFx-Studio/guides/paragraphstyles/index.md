## Define a paragraph style

Open the **Resource Panel** > **Brand Kit panel**.

![Pink arrow pointing at the Resources icon at the foot of the left tool bar](bottom-quicktools-ui.png){.screenshotsmall}

![Resources panel listing Brand Kit, Media, Data source and Barcodes](bk1.png){.screenshot}

Select the last tab to view paragraph- and character styles

![Brand Kit panel on its last tab, with the Paragraph styles and Character styles sections both empty](bk5.png){.screenshot}

Click on the "+" sign to ad a new paragraph style.
Each click on the "+" sign will add another (empty) paragraph style.

![Close-up of the Paragraph styles header and the "+" button used to add each style](ps-3.png){.screenshot}

Click on the "..." menu next to the newly created paragraph style and choose edit or click the pencil to edit the style.

Set all properties you want for this paragraph. Saving happens automatically.

![Edit Style panel for the Heading paragraph style, with the Custom RGB Color picker open beside it](bk8.png){.screenshot-full}

## Apply a paragraph style

Set the text-cursor anywhere in a paragraph. You can also select (part of) the paragraph.
A paragraph is defined between the start of a sentence, up to the end-of-line character.

In the properties panel on the right, select the paragraph style from the dropdown list.

![Text style section of the properties panel with the Paragraph style dropdown open on Paragraph Style 1](ps-6.png){.screenshot}
